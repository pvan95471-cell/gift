HƯỚNG DẪN NHẠC NỀN (BACKGROUND MUSIC)
==================================================

1. Nhạc nền hiện tại:
   - Bản nhạc: Attack on Titan OST - "Call of Silence" (Hiroyuki Sawano).
   - Phong cách: Piano Acoustic Instrumental du dương, sâu lắng, ấm áp và giàu cảm xúc.
   - File đã được tạo sẵn tại: "assets/music/background.mp3" và "background.wav".

2. Tích hợp dự phòng:
   - Hệ thống có tích hợp sẵn bộ phát âm thanh Web Audio API Synthesizer hợp âm "Call of Silence" phòng trường hợp mạng chậm hoặc thiết bị chặn file audio.

3. Thay đổi bài hát khác (nếu muốn):
   - Copy file MP3 bài hát bạn muốn vào thư mục này.
   - Đặt tên là "background.mp3" (ghi đè file hiện tại), hoặc cập nhật đường dẫn trong "js/config.js".
